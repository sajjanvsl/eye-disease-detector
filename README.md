# 🧿 Eye Disease Detection & Classification (Streamlit App)

This project is developed by BCA VI Sem students of Govt. First Grade College for Women, Jamkhandi.

## 🚀 Features
- Upload eye images for disease detection
- Model prediction with confidence score
- Confusion matrix visualization
- PDF report generation
- Multiple image handling

## 🧠 Diseases Classified
- Cataract
- Glaucoma
- Normal
- Other

## 🛠️ How to Run
1. Clone this repo or download the folder
2. Install requirements:
   ```
   pip install -r requirements.txt
   ```
3. Launch the app:
   ```
   streamlit run app.py
   ```
